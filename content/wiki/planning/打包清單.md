# 打包清單

針對美國 47 天旅遊的打包清單。

---

## 證件與財務

- [ ] 護照（確認有效期 6 個月以上）
- [ ] 信用卡（建議帶 2 張不同銀行）
- [ ] 少量現金（美金）
- [ ] 緊急聯絡資訊（紙本備份）
- [ ] 護照影本（與正本分開存放）
- [ ] 國際駕照（若要租車）

---

## 電子設備

- [ ] 手機 + 充電線
- [ ] 行動電源
- [ ] 美國插座轉接頭（A/B 型，台灣電器通常可直接使用）
- [ ] 相機（若有）
- [ ] 耳機
- [ ] eSIM 或美國 SIM 卡（參考 [[wiki/logistics/網路與通訊]]）

---

## 衣物（長途旅行建議）

- [ ] 上衣 × 7–10（可重複穿，快乾材質佳）
- [ ] 褲子 × 3–4
- [ ] 內衣褲 × 7
- [ ] 襪子 × 7
- [ ] 薄外套（舊金山夏天有霧，早晚涼）
- [ ] 厚外套（優勝美地山區、棕櫚泉空中纜車山頂極冷）
- [ ] 泳衣（棕櫚泉飯店泳池、聖地牙哥海灘）
- [ ] 舒適步行鞋（每天走很多路）
- [ ] 涼鞋/拖鞋

---

## 盥洗與健康

- [ ] 牙刷、牙膏
- [ ] 洗髮精、沐浴乳（小瓶，或到當地超市買）
- [ ] 防曬乳 SPF50+（美國戶外活動多，必備）
- [ ] 保濕乳液（沙漠地區極乾燥）
- [ ] 常備藥（止痛藥、腸胃藥、感冒藥）
- [ ] OK 繃、消毒藥水
- [ ] 口罩

---

## 旅行便利

- [ ] 旅行枕（長途飛行）
- [ ] 眼罩、耳塞
- [ ] 可折疊購物袋
- [ ] 密封袋（防漏液體）
- [ ] 雨傘或輕便雨衣（舊金山夏天偶有霧雨）

---

## 戶外 / 國家公園專用

- [ ] 遮陽帽（優勝美地、約書亞樹、羚羊峽谷必備）
- [ ] 太陽眼鏡
- [ ] 大容量水壺（國家公園內無販賣機）
- [ ] 好走的健行鞋（優勝美地步道）
- [ ] 防水外套（優勝美地瀑布水氣大）
