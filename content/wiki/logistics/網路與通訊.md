# 美國上網方案

---

## 推薦方案

| 方案 | 說明 |
|------|------|
| **eSIM（推薦）** | 不換卡，出發前設定好，Airalo / Nomad / Holafly |
| **美國 SIM 卡** | T-Mobile 或 AT&T，可在台灣宅配到府 |
| **美加墨三國卡** | 若行程跨越加拿大或墨西哥 |

---

## 注意事項

- 優勝美地、約書亞樹等國家公園**手機訊號極差**，提前下載 Google Maps 離線地圖
- 公共 Wi-Fi 避免使用網路銀行
- 舊金山飯店 Wi-Fi 通常穩定，可作為備用

---

## 實用 App（出發前下載）

| App | 用途 |
|-----|------|
| Google Maps（含離線地圖）| 導航，國家公園必備 |
| Uber / Lyft | 叫車 |
| Google Translate | 即時翻譯 |
| XE Currency | 匯率換算 |
| Yelp | 餐廳評價 |
